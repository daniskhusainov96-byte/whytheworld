# Бот «Данисик»: из Телеграма прямо в код

Вы пересылаете боту пост, видео, фото или пишете идею. Бот:

1. сохраняет это в папку `inbox/` репозитория (текст, фото, кадры из видео);
2. отправляет в Claude и присылает вам в ответ 5 вариантов похожего контента для вашего канала;
3. в сессии Claude Code можно написать «посмотри inbox» и продолжить работу с этим материалом.

Бот работает бесплатно на GitHub Actions: проверяет новые сообщения раз в 10 минут. Свой компьютер включённым держать не нужно.

## Настройка (один раз, ~10 минут)

### 1. Токен бота
Напишите [@BotFather](https://t.me/BotFather) команду `/mybots`, выберите бота «Данисик» → **API Token**. Если бота ещё нет: `/newbot`.

### 2. Ваш Telegram id
Откройте [@userinfobot](https://t.me/userinfobot) и нажмите Start. Он пришлёт ваш id (число). Бот отвечает только на этот id, чужие сообщения игнорирует.

### 3. Ключ Claude API (для генерации ответов)
Зарегистрируйтесь на [platform.claude.com](https://platform.claude.com), пополните баланс и создайте ключ в разделе API Keys. Это отдельная оплата от подписки Claude, по факту использования: один ответ стоит примерно $0.03–0.10 (дороже, когда в сообщении видео: Claude смотрит 4 кадра).

Без ключа бот тоже работает, но только сохраняет присланное в `inbox/`.

### 4. Секреты в GitHub
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте три секрета:

| Название | Что вставить |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `ALLOWED_USER_IDS` | ваш id из шага 2 |
| `ANTHROPIC_API_KEY` | ключ из шага 3 |

### 5. Включить
Вкладка **Actions** → «Danisik bot» → **Run workflow**. Дальше он запускается сам каждые 10 минут.

Проверка: напишите боту `/start`, через 10 минут придёт подсказка.

## Как пользоваться

- **Переслали чужой пост** → бот разберёт приём и даст 5 вариантов на ту же тему: страны, путешествия, Таро.
- **Своё видео/фото с подписью** («подпись под рилс», «пост про массаж, коротко») → сделает именно это.
- **`/save` в начале сообщения** → только сохранит, без генерации.
- **`/id`** → покажет ваш id.

Стиль ответов задаётся в файле `bot/style_prompt.md`, его можно править.

## Ограничения

- Видео больше 20 МБ Телеграм не даёт боту скачать: тогда сохраняется только обложка и подпись. Короткие рилсы обычно влезают.
- Claude видит кадры из видео и подпись, но не слышит звук: озвучку лучше продублировать текстом.
- GitHub запускает расписание с задержкой, ответ приходит через 10–20 минут, а не мгновенно. Если нужно мгновенно, бота можно запустить на своём компьютере или сервере: `pip install -r bot/requirements.txt`, затем `python bot/danisik_bot.py` с теми же тремя переменными окружения.

## Важно про приватность

Всё, что вы присылаете боту, попадает в папку `inbox/` этого репозитория. Если репозиторий публичный (сайт на GitHub Pages), эти файлы увидят все. Не присылайте боту личное или сделайте для бота отдельный приватный репозиторий: скопируйте туда папки `bot/`, `inbox/` и `.github/`.

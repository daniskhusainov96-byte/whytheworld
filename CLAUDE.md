# Правила работы

## Самопроверка перед выдачей
Перед тем как отдать любой результат (текст, промпт, код, команды, данные):
1. Перепроверь его по всем правилам и скиллам из этого файла.
2. Проверь, нет ли в нём запрещённых слов и фраз.
3. Проверь факты, цифры и нумерологию; ничего не выдумывай.
4. Если нашла ошибку, исправь и проверь заново.
Отдавай только готовый проверенный вариант, без черновиков.

## Входящие из Телеграма
Бот «Данисик» складывает присланные ему тексты, фото и кадры из видео в папку `inbox/` (по дням). Если просят «посмотри inbox», «сделай похожее на последнее», бери самые свежие файлы оттуда: читай `.md`, смотри картинки рядом, делай похожий контент по правилам этого файла. Код бота лежит в `bot/`, правила стиля для ответов бота — в `bot/style_prompt.md`.

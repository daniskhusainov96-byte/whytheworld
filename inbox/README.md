# Входящие от бота «Данисик»

Сюда бот складывает всё, что вы присылаете ему в Телеграме:

- `ГГГГ-ММ-ДД/ЧЧММСС_id.md` — текст сообщения и откуда переслано;
- `.jpg` рядом — фото или кадры из видео;
- `.answer.md` — варианты, которые Claude уже прислал в ответ.

В сессии Claude Code достаточно написать «посмотри inbox» или «сделай похожее на последнее из inbox».
